# 위험성평가 재검토

위험성평가표(엑셀/CSV)를 올리면 유효성을 자동으로 재검토하는 웹사이트입니다.

## 기능
- **파일 처리**: `.xlsx` `.xls` `.xlsm` `.csv` 지원. 파일은 브라우저 안에서만 분석됩니다(서버 업로드 없음).
- **양식 자동 인식**: 2단 병합 헤더(현재 위험성 / 개선 후 위험성 → 가능성·중대성·위험성)까지 인식, 위험성평가 시트 자동 선택.
- **규칙 기반 검토** (「사업장 위험성평가에 관한 지침」 기준)
  - 필수 항목(유해·위험요인, 가능성, 중대성, 위험성, 감소대책, 개선 후 위험성, 담당자, 일정) 누락
  - 위험성 계산 오류(곱셈/덧셈 자동 판별), 척도 범위 초과
  - 허용 기준 초과 항목의 감소대책 누락
  - ‘주의·교육·준수’ 같은 형식적 대책, 보호구 위주 대책
  - 개선 후 위험성 미기재·증가·미감소·과도한 감소(과소평가 의심)
  - 중대재해 유형(추락·끼임·감전·화재 등)의 중대성 과소평가
  - 개선 예정일 경과 미완료, 담당자 미지정, 중복 항목
  - 평가일 1년 경과(정기평가), 근로자 참여 기록 미확인
- **결과 다운로드**: 요약 / 지적사항 / 원본+검토결과 열이 포함된 엑셀
- **AI 정밀 검토(선택)**: 누락 위험요인, 대책 적정성 등 내용 기반 검토 (Claude API)

## 배포 (Vercel)
1. 이 폴더를 GitHub 저장소로 올린 뒤 Vercel에서 **Add New → Project → Import**
   (Framework Preset: Other, 빌드 설정은 기본값 그대로)
   또는 CLI: `npx vercel --prod`
2. AI 정밀 검토를 쓰려면 Vercel 프로젝트 **Settings → Environment Variables**에
   `ANTHROPIC_API_KEY` 를 추가하고 재배포합니다. (없어도 규칙 기반 검토는 동작)

## 로컬 실행
```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 샘플 파일로 분석기 테스트
```

## 구조
- `public/analyzer.js` — 규칙 기반 검사기 (허용 기준·척도는 화면에서 조정 가능)
- `public/app.js` — 화면/엑셀 처리
- `api/review.js` — AI 검토 서버리스 함수
