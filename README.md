# 위험성평가 보완목록

위험성평가표(엑셀/CSV)를 올리면 **원본 평가표의 표 바로 오른쪽 열에 ‘보완목록’ 작성란**을 붙여 주는 웹사이트입니다.
자동 판정은 하지 않고, 각 위험요인 행 옆에서 유효성 검토와 보완 내용을 바로(수기) 작성할 수 있게 합니다.

## 사용 방법
1. 사이트에 위험성평가표 파일을 올립니다. (평가표가 있는 시트는 자동 선택, 필요하면 직접 변경)
2. 인식된 평가 항목을 미리보기로 확인합니다.
3. **작성란 붙여서 받기**를 누르면 `원래파일명_보완목록.xlsx` 가 내려받아집니다.

## 추가되는 작성란 (원본 표의 마지막 사용 열 다음부터)
- **직접 작성(노랑)**: 유효성 검토 판정(적정/보완필요/해당없음/보완완료 목록 선택, 색 자동 변경), 보완 필요 사항, 보완 대책, 보완후 빈도·강도, 담당자, 완료 예정일, 완료 확인, 비고
- **자동 계산(파랑)**: 보완후 위험도, 머리글 위 진행 현황(전체·검토·보완필요·보완완료·미검토)
- 원본이 2단 머리글이면 작성란도 2단으로 맞추고, 원본 글꼴 크기를 따릅니다. 인쇄 영역이 지정돼 있으면 작성란까지 넓힙니다.
- 원본의 기존 셀·서식·행 높이는 바꾸지 않습니다.

## 참고
- 파일은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.
- `.xls` / `.csv` 는 원본을 그대로 수정할 수 없어 값만 옮긴 새 `.xlsx` 로 만들어집니다. `.xlsm` 은 매크로가 빠집니다.
- 원본의 그림·도형은 보존되지 않을 수 있으니 받은 파일을 한 번 확인해 주세요.

## 배포 (Vercel)
GitHub 저장소를 Vercel에 연결해 두면 `main` 에 올릴 때마다 자동 배포됩니다. (빌드 설정 없음, 정적 사이트)

## 로컬 실행
```bash
npm install
npm run dev     # http://localhost:3000
```

## 구조
- `public/analyzer.js` — 평가표 양식 인식(헤더·열 판별, 항목 추출)
- `public/app.js` — 화면, 보완목록 시트 생성(ExcelJS)
- `scripts/` — 테스트용 샘플 생성 및 로컬 서버
